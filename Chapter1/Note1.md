# 딥러닝 파이토치 교과서

========================================================================================================================================================================================
## 1. 머신러닝과 딥러닝

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
### 1.1 인공지능, 머신 러닝과 딥러닝

- 인공지능(Artificial Intelligence, AI): 인간의 지능을 모방하여 사람이 하는 일을 컴퓨터가 할 수 있도록 하는 기술
- 인공지능 > 머신러닝(인공신경망, 서포트 벡터 머신, 결정 트리) > 딥러닝(CNN, RNN, RBN)
- 머신러닝은 데이터를 인간이 전처리(데이터의 특징을 스스로 추출하지 못함)
- 딥러닝은 대량의 데이터를 신경망에 적용하여 컴퓨터가 특성 추출

|구분|머신러닝|딥러닝|
|-----|-----|-----|
|동작원리|데이터에 알고리즘 적용하여 예측|신경망을 사용하여 특징 및 관계 해석|
|재사용|재사용 X|동일할 유형의 데이터를 분석하는 데 재사용|
|데이터|수천개|수백만개 이상|
|훈련 시간|단시간|장시간|
|결과|숫자|대부분 가능|

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
### 1.2 머신 러닝이란

- 머신러닝: 컴퓨터 스스로 대용량 데이터에서 지식이나 패턴을 찾아 학습하고 예측을 수행하는 것(컴퓨터가 수행할 수 있게 알고리즘과 기술을 개발하는 분야)

#### 1.2.1 머신 러닝 학습 과정
- 크게 학습 단계(learning)와 예측 단계(prediction)로 구분할 수 있다.

<학습 단계>
레이블---------------------------------------> 분류/예측모델(모형)
데이터 -> 특성 추출 -> 머신러닝 알고리즘 적용 -> 분류/예측모델(모형)

<예측 단계>
대이터 -> 특성 추출 -> 분류/예측 모델(모형) -> 결과값

- 레이블: 지도 학습에서 정답
- 특성 추출 : 데이터별로 특징을 찾아낸 것을 토대로 벡터로 변환하는 작업
- 데이터: 특징이 잘 반영되고 편향되지 않은 훈련 데이터를 확보하는 것이 중요
 데이터 = 훈련 데이터(80%) + 테스트 데이터(20%)
 훈련 데이터 = 훈련 데이터 + 검증 데이터
 - 검증 데이터셋을 사용하는 이유: 모델 성능 평가를 위해, 데이터셋의 양이 많지 않다면 사용하지 않는 것이 좋음
 - 모델 성능 평가가 필요한 이유
 1. 테스트 데이터 셋에 성능을 가늠
 2. 모델 성능을 높이는 데 도움
 - 과적합이 발생했을 경우 정규화 또는 에포크(epoch)를 줄이는 방식으로 해결

- 모델(가설): 학습 단계에서 얻은 최종 결과물
1. 모델 선택
2. 모델 학습 및 평가
3. 모델 업데이트
세 단계를 반복하면서 가장 성능 좋은 모델을 찾는다.

#### 1.2.2 머신 러닝 학습 알고리즘
머신러닝의 학습 알고리즘: 지도학습, 비지도 학습, 강화학습
지도학습: 정답이 무엇인지 컴퓨터에 알려주고 학습시키는 방법, 명확한 분류 가능
 - 분류: K-최근접 이웃(KNN), 서포트 벡터 머신(SVM), 결정 트리, 로지스틱 회귀
 - 회귀: 선형 회귀
비지도 학습: 정답을 알려주지 않고 특징을 클러스터링(범주화)하여 예측하는 방법, 유사도 기반(데이터 간 거리 측정) 클러스터링
 - 군집: K- 평균 군집화, 밀도 기반 군집 분석(DBSCAN)
 - 차원 축소: 주성분 분석(PCA)
강화학습: 자신의 행동에 대한 보상을 받으며 학습
 - 마르코프 결정 과정

### 1.3 딥러닝이란
- 딥러닝: 인간의 신경망 원리를 모방한 심층 신경망 이론을 기반으로 고안된 머신 러닝 방법

#### 1.3.1 딥러닝 학습 과정
데이터 준비 -> 모델(모형) 정의 -> 모델(모형) 컴파일<옵티마이저 선택, 손실 함수 선택> -> 모델(모형) 훈련 -> 모델(모형) 예측
<데이터 준비>
1. 파이토치나 케라스에서 제공하는 데이터셋을 사용
2. 캐글같은 플랫폼에서 공개된 데이터를 사용

<모델(모형) 정의>
- 신경망 생성
- 은닉층 개수가 많을 수록 성능이 좋아지지만 과적합 발생 확률이 높음

<모델(모형) 컴파일>
- 활성화 함수(시그모이드, 하이퍼볼릭 탄젠트, 렐루), 손실 함수(평균제곱 오차, 므로스 엔트로피 오차), 옵티마이저(아담(Adam), 알엠에스프롭(RMSProp)) 선택
 활성화 함수: 입력 신호가 일정 기준 이상이면 출력 신호로 변환하는 함수
 손실함수: 모델의 출력 값과 사용자가 원하는 출력 값의 차이
 옵티마이저: 손실 함수를 기반으로 결정
- 훈련 데이터셋 형태가 연속형이면 평균 제곱 오차(MSE) 사용
- 이진 분류라면 크로스 엔트로피(cross entropy)선택
- 과적합을 피할 수 있는 활성화 함수, 옵티마이저 선택이 중요

<모델(모형) 훈련>
- 배치: 일정한 묶음으로 나누어 처리
- 에포크: 훈련의 횟수
- 훈련 과정에서 값의 변화를 시각적으로 표현하여 눈으로 확인하면서 파라미터와 하이퍼파라미터에 대한 최적의 값을 찾기
 파라미터: 모델 내부에서 결정되는 변수
 하이퍼파라미터: 튜닝 또는 최적화해야 하는 변수로, 사람들이 선험적으로 설정하는 변수
성능이 좋다 = 정확도와 속도가 높다.

<모델(모형) 예측>
- 검증 데이터셋을 생성한 모델(모형)에 적용하여 실제로 예측을 진행(예측력이 낮다면 파라미터를 튜닝하거나 신경망 재설계)

딥러닝 학습 과정에서 중요한 핵십 구성 요소는 신경망과 역전파이다.
심층 신경망에는 데이터셋의 어떤 특성들이 중요한지 스스로에게 가르쳐 줄 수 있는 기능이 있다.
가중치 값을 업데이트하기 위한 역전파가 중요하다.
역전파 계산 과정에서 사용되는 미분(오차를 각 가중치로 미분)이 성능에 영향을 미치는 주요한 요소
- 파이토치 같은 프레임워크를 이용하면 역전파 알고리즘을 자동으로 처리해 주기 때문에 딥러닝 알고리즘 구현이 간단하고 편리

#### 1.3.2 딥러닝 학습 알고리즘
활용 분야에 따라 지도학습, 비지도 학습, 전이 학습으로 분류
1. 지도학습
- 이미지 분류 : 이미지 또는 비디오상의 객체를 식별하는 컴퓨터 비전 기술(합성곱 신경망(CNN))
- 이미지 인식: 사진을 분석하여 사물의 종류를 인식
- 이미지 분할: 영상에서 사물이나 배경 등 객체 간 영역을 픽셀 단위로 구분하는 기술
- 시계열 데이터를 분류할 때 사용되는 순환 신경망(RNN) -> 역전파 과정에서 기울기 소멸 문제가 발생하는 단점
-> LSTM(Long Short-Term Memory)
 1. 망각 게이트: 과거 정보를 잊기 위한 게이트
 2. 입력 게이트: 현재 정보를 기억하기 위한 게이트
 3. 출력 게이트: 최종 결과를 위한 게이트

2. 비지도 학습
- 워드 임베딩과 군집
<워드 임베딩>
- 자연어(사람의 언어)를 컴퓨터가 이해하고 효율적으로 처리할 수 있게 변환
- 워드 임베딩(Word embedding)를 이용하여 단어를 벡터로 표현(워드투벡터(Word2Vec), 글로브(GloVe))
<군집>
- 아무런 정보가 없는 상태에서 데이터를 분류하는 방법
- 머신러닝 단독으로 적용하기보다 딥러닝과 함께 사용하면 좋음

3. 전이 학습
- 사전에 완료된 모델 사전학습모델(pre-trained model)을 가지고 원하는 학습에 미세 조정 기법을 이용하여 학습시키는 방법
- 사전학습모델: 풀고자 하는 문제와 비슷하면서 많은 데이터로 이미 학습이 되어 있는 모델(VGG, 인셉션(Inception), MobileNet)
